Employee Raise Issue – ServiceNow

This project is developed in ServiceNow to provide a simple and user-friendly solution for employees to raise their workplace issues or requests.

The application allows employees to submit issues through a Service Portal. The submitted requests are stored in a custom table and can be managed by the support team.

Key Features
Custom ServiceNow application for Employee Raise Issue.
Custom table with fields such as Requester, Category, Subcategory, State, Priority, and Assignment Group.
Record Producer for submitting employee issues.
UI Policies to make fields mandatory and read-only based on conditions.
Category and Subcategory dependency for accurate issue selection.
Custom Service Portal for employees to access the issue submission form.
Custom widgets to provide an easy and attractive portal interface.
Testing and validation of the complete issue submission process.
Project Flow

Employee → Service Portal → Raise Issue → Record Producer → Custom Table → Support Team → Issue Resolution

This project helps to standardize issue submission, reduce manual work, maintain accurate information, and improve the overall employee support process.
